A폰은 촬영만, B폰은 트랙맨처럼 스윙 결과를 확인하는 화면이 됩니다.

⚠️ 이 화면에서는 카메라와 폰 간 연결이 막혀 있어요.
앱 안의 미리보기가 아니라, Safari/Chrome 주소창에서 이 페이지 주소를 직접 열어야 동작해요. (HTTPS 주소로 호스팅 필요)
사용 순서
1. B폰(확인용)에서 "확인 화면 시작" → 코드 확인
2. A폰(촬영용)에서 코드 입력 → 삼각대에 세우기
3. A폰 촬영 버튼, 또는 B폰의 "원격 촬영"으로 시작
4. 스윙이 끝나면 B폰에 슬로우 모션 + 자세 분석이 자동으로 표시돼요

촬영 팁 정면 또는 공 뒤쪽, 허리 높이, 3m 거리, 전신이 보이게. 같은 Wi-Fi가 가장 안정적이에요.
공 속도·스핀 같은 레이더 수치는 측정할 수 없고, 분석 값은 카메라 기반 추정값이에요.
